# Hán Tự (Android)

Bản Android của app học tiếng Trung Hán Tự: tra từ, lộ trình HSK 1–9, ôn tập kiểu Leitner, đọc bằng giọng tiếng Trung của máy.

Dữ liệu từ nằm ở `app/src/main/assets/phrases.json` (cùng định dạng với bản iOS).

Build APK debug bằng GitHub Actions (artifact `HanTu-debug-apk`), cài trực tiếp được trên điện thoại Android.
